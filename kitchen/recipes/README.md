# Recipes

One file per recipe: `kebab-case-name.md`. Keep the user's wording and
quantities exactly as given. Don't "improve" a recipe unless asked.

Template:

```markdown
# Recipe name

- Source: (who / where it came from, if known)
- Serves: / Prep: / Cook:

## Ingredients
- 1 lb ground beef
- ...

## Directions
1. ...

## Notes
- (substitutions, tweaks, what the household likes)
```

When planning groceries, compare a recipe's ingredients to `../staples.md`
and any fresh inventory photos, and list only what's missing.
